    Chasing a moving optimum: the mistake no Bayesian optimizer can avoid

    When the optimum of a time-varying problem keeps moving, can a Bayesian optimizer eventually stop making mistakes? Only if the changes can be predicted from the past; otherwise, every optimizer makes a mistake at every step, of a size set by the problem. Any system that must keep learning after deployment, from a controller to an LLM, faces the same limit.
